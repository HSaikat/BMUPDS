# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public GitHub issue.

Instead, report it privately by emailing: **shsamudro2000@gmail.com**

Please include:
- A description of the vulnerability
- Steps to reproduce it
- Potential impact

You can expect an acknowledgement within **48 hours** and a status update within **7 days**. If the vulnerability is confirmed, a fix will be prioritized and you will be credited (unless you prefer otherwise). If declined, a reason will be provided.
